# Cursor

**SSE:** поддерживается напрямую, мост не нужен.

**Команды «добавить сервер одной строкой» у Cursor нет.** У `cursor-agent mcp`
только `list`, `list-tools`, `login`, `enable`, `disable`; серверы задаются файлом.
Так что здесь — правка JSON, зато короткая.

## Файлы конфигурации

| Область | Путь |
|---------|------|
| Проект | `.cursor/mcp.json` в корне проекта |
| Глобально (macOS, Linux) | `~/.cursor/mcp.json` |
| Глобально (Windows) | по аналогии `%USERPROFILE%\.cursor\mcp.json` — **в официальной документации путь для Windows не указан** |

Через интерфейс: страница **Customize** — там же список установленных MCP-серверов
и переключатели.

## Конфигурация — без токена

```json
{
  "mcpServers": {
    "ozon": {
      "url": "http://localhost:8000/sse"
    }
  }
}
```

## Конфигурация — с `MCP_AUTH_TOKEN`

```json
{
  "mcpServers": {
    "ozon": {
      "url": "http://localhost:8000/sse",
      "headers": {
        "Authorization": "Bearer ${env:OZON_MCP_TOKEN}"
      }
    }
  }
}
```

Подстановка `${env:NAME}`, `${userHome}`, `${workspaceFolder}` работает в полях
`command`, `args`, `env`, `url`, `headers`. Переменная должна быть в окружении,
из которого запущен Cursor, иначе подставится пустая строка (`envFile` для
удалённых серверов не работает — только для stdio).

Токен можно передать и параметром URL, если возиться с окружением не хочется:
`http://localhost:8000/sse?token=<MCP_AUTH_TOKEN>` — сервер это поддерживает.
Учтите, что токен окажется в файле конфигурации в открытом виде.

## Проверка

- Страница **Customize** — сервер `ozon` и список его инструментов.
- Логи: **Cmd+Shift+U** (Output) → в выпадающем списке **MCP Logs** — там видны
  ошибки подключения и аутентификации.

## Оговорки

- Поле `type` у удалённых серверов в документации Cursor не описано — указывайте
  только `url` и `headers`. `"type": "stdio"` нужен лишь локальным процессам.
- Cursor не различает SSE и Streamable HTTP в конфиге — тип определяется
  эндпоинтом, поэтому URL должен заканчиваться именно на `/sse`.
- Незашифрованный `http://localhost` допустим, в официальном примере он и стоит.
- Явного индикатора статуса («зелёная точка») в текущей документации нет —
  ориентируйтесь на MCP Logs и на то, появились ли инструменты.
